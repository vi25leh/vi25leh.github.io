# The Command-line Course

The Command-line course serves as an introduction to working on the command-line and using the terminal for executing different kinds of tasks. The starting point is from very basic commands to handle directories and files. From there the contents shift into more complex commands and combining them in order to modify files and create new ones with a specific purpose. Then scripting is introduced alongside with environment variables and configuration files. This allows the modification of the terminal for a more efficient and personalised experience on the command-line. Installing software allows for executing programs and retrieving specific information from files. After that, the use of remote servers and their benefits is discussed. The course ends with the theme of version control and GitHub. The final project of creating a personal webpage with GitHub Pages allows the student to put all the knowledge acquired throughout the course into use.

The methods learned on this course can be very useful for linguists who use technological tools in their work/studies and want to find ways to work more efficiently.

## Module 1: Introduction to Command-line Environments

During the first module, we went through the very basics of the Command-line starting from setting up the terminal on our own devices.

### Contents

* Directories
    * Getting familiar with the root directory and its functions
    * Creating, removing and copying directories
    * Displaying the contents of a directory
    * Changing the contents of a directory
* Files
    * Creating, copying, renaming and moving files
    * Displaying the contents of a text file using '$ less'
    * Opening and editing a text file on a text editor
    * Retrieving files from the internet using '$ wget':
````
$ wget https://linktothefile.txt
````
        * The 'wget'-command downloads the retrieved file from the internet into the current directory
